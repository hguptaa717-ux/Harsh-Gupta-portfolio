## Project overview

I prepared and transformed a telecom customer dataset from Kaggle, then built an interactive Tableau dashboard to explore customer churn.

## Dashboard

The dashboard summarizes 7,043 customers, including 1,869 who churned, for an overall churn rate of 26.5%. It compares churn patterns across contract types, internet services, tech support, gender, and senior-citizen status.

Viewers can select Male or Female to filter the dashboard and see the visualizations update for that group. The dashboard also summarizes reported churn reasons, including randomly dropping speeds and unanswered support calls.
